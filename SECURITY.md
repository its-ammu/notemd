# Security

If you find a vulnerability in NoteMD, please email
[amuthavarsnirajkumar@gmail.com](mailto:amuthavarsnirajkumar@gmail.com)
instead of opening a public issue.

Include:

- a description of the issue
- steps to reproduce
- impact (for example: other users' data, auth bypass, key leak)

I will acknowledge the report and follow up. Please give a reasonable window
to fix before any public disclosure.
