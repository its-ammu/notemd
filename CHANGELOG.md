# Changelog

## 0.1.1 — 2026-09-16

- Change a meeting's date from the editor (web and iOS)
- Set an end date on repeating meetings
- Keep the meeting dialog open while using the calendar

## 0.1.0 — 2026-09-16

First public release.

- Home dashboard for today: tasks, meetings, and recent pages
- Markdown notebooks with preview, tags, images, and public page sharing
- Weekly tracker with day / workweek / week views and recurring meetings
- Pomodoro timer and a radio tab
- Web app (React + Vite), optional Tauri desktop and iOS shells
- Self-host with Supabase; note content is encrypted in the browser before it is stored
